# ikd1d-py

Python port of **IKD1D**, which analyses isokinetic dynamometry (IKD) torque-angle profiles as one-dimensional observations. The original MATLAB app (LJMU, v0.03) is kept unchanged in [`legacy/matlab/`](legacy/matlab) as the reference implementation.

Status: Phase 0 skeleton – see [docs/roadmap.md](docs/roadmap.md).

```
pip install -e ".[dev]"
pytest
```
