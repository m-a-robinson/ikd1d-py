# Roadmap

- **Phase 0** – package skeleton, CI, MATLAB code frozen in `legacy/matlab/`.
- **Phase 1** – pure-function library: `io`, `correction`, `segment`, `fit`, `resample`.
- **Phase 2** – golden-output regression tests against MATLAB/Octave using `tests/data/`.
- **Phase 3** – CLI, notebooks, optional GUI.
- **Phase 4** – 1D statistics (e.g. `spm1d`), more manufacturers, PyPI release.
